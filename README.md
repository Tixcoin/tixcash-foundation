# Tixcash Foundation

Official foundation portal and infrastructure for the Tixcash ecosystem.

## Overview

The Tixcash Foundation manages the long-term development and growth of the Tixcash network. This repository contains:

- **Block Explorer client**: Frontend for browsing Tixcash transactions and blocks
- **Data API service**: Backend API for querying blockchain data
- **Feed service**: Real-time data feed for network activity

## Structure

```
tix_Explorer/     - Blockchain explorer frontend (React)
dataAPI/          - REST API for blockchain data
feed.data/        - Network data feed service
tix_BlockService/ - Block processing utilities
```

## Foundation Mandate

The Foundation Fund (13% of total supply) is reserved for:
- Global market expansion
- Strategic ecosystem management
- Long-term protocol maintenance
- Developer grants and community initiatives
